为什么我选择做一个静态博客

在动手之前，我也纠结过：是租一台服务器装博客系统，还是自己写一个静态网站？最后我选了后者。理由有这么几个：

1. 几乎不花钱

静态网站就是一堆 HTML 文件，可以免费托管在 GitHub Pages 上。不买域名的话，连一分钱都不用花；以后想要自己的域名，一年也就几十块。

2. 速度快、不用维护

没有数据库，没有后台程序，页面打开很快，也不用担心被攻击、要打补丁。对我来说，省下来的心思可以用来多写点内容。

3. 内容完全属于自己

所有文章都是一个一个的文件，随时可以打包带走，换到任何平台都能继续用，不会被任何服务商绑架。

4. 唯一的"代价"

代价是没有网页后台，发文章需要编辑文件。但对一个更新频率不高的个人博客来说，这个代价完全可以接受，甚至有点享受这种朴素感。

网站的本质，是内容，而不是技术。
