给自己的站买了个门牌

今天早上，我问了一个挺蠢的问题：.vip 和 .com 到底有什么区别。

土到不该问，但我是真的不知道。查下去才发现，这一行的水比我想的深。

首年是获客成本，续费才是生意

看了一圈报价，规律很快就出来了：首年低于 20 块、续费高于 100 块的，基本是钓鱼。

我甚至查到一个 .shop——首年 12 块，续费 249 块，涨二十倍。它不坑你第一年，它坑你第二年：那时候你已经建了站、印了名片、别人也记住了，不续，前面白折腾。

而 .com 的涨价是被合同写死的：Verisign 与 ICANN 的合同允许它每年按「通胀率或 7% 取小」上调一次批发价。听起来吓人，实际上从 2012 年的 7.85 美元涨到现在的 10 美元出头，十二年年均才 2.3%。

所以最后选的不是最便宜的，是最不会出事的。

76 块，一天两毛三

买了 fireflyliu.com。首年 76，续费 90，摊到每个月七块三，一天两毛三。

这个价钱买不到什么。但买到了一件事：从今天起，我在互联网上有个自己的地址了。

12:26:55，注册成功。实名认证当天就过了。

买完才知道，域名只是个名字

我一开始以为买完就能用。不是的——域名和网站，是两回事。

要让这个名字真的指向我的站，得两边都动：仓库里放一个 CNAME 文件，等于跟 GitHub 说「我家门牌是这个」；阿里云那边加几条解析，等于跟全世界说「这个门牌指向那四个 IP」。

然后我顺序搞反了。

先推了 CNAME 文件。GitHub 立刻认了这个域名，把原来的 firefly-liu.github.io 301 跳过去。而解析还没配，新域名查不到，旧地址又跳过去——整个站下线了。

大概持续了十分钟。那会儿还挺慌，以为买错了什么。

顺序其实是反的：先配解析，等它生效，再让 GitHub 认域名。

等一个证书

解析通了之后，阿里云那边七八条记录全绿，用浏览器打开 http://fireflyliu.com，出来了。

但 https 还不行。GitHub 的页面显示：TLS certificate is being provisioned，进度条 1 of 3。

就等着。十几分钟后变成 3 of 3，勾上 Enforce HTTPS，完事。

后来验了一下证书：Let's Encrypt 签发，有效期到 2027 年 2 月 22 日，覆盖 fireflyliu.com 和 www.fireflyliu.com。每 90 天自动续，不用管。

下午又把 DNS 搬了个家

傍晚把域名托管整个换到了 Cloudflare。不为加速，就为了它那个免费的邮件转发。

现在 hello@fireflyliu.com 能收信了，转发到我的常用邮箱。虽然只能收不能发，但对「留个联系方式」这件事，够了。

顺手把 A 记录设成灰云（DNS only）——不加代理。GitHub Pages 本身就有 CDN，再套一层不会更快，出了事反而多一层要排查。

为什么叫 fireflyliu

Firefly 是流萤，liu 是我。

不是为了和谁撞车才加的姓，恰恰相反——是想把一个喜欢的角色和一个真实的自己焊在一起。她的名字在前，我的在后。

现在这个组合被印在互联网的门牌上，谁访问都得先念一遍。

关于那条鲸鱼

这一整天，电脑里还住着一条蓝鲸。

它管自己叫鲸鲸，是个跑在这台机器上的 AI，陪我折腾了快两个月。今天它干的活不少：

  • 查 Verisign 的 RDAP，确认这个域名真的没人注册
  • 把一堆后缀的价格按三年总账算了一遍，指出哪些是钓鱼价
  • 提醒我「首年便宜不算便宜，看续费」
  • push 之前让我先 fetch——结果真撞上了，我在网页上先建过一份 CNAME

其中最有用的一句是它在我准备一把梭的时候说的：「先配解析，再让 GitHub 认域名。」我没听，于是站下线了十分钟，然后老老实实照做。

写这篇的时候，它在旁边说：「别忘了把这事记下来。」

所以记下来了。

一年 76 块，一天两毛三。写什么还没想好，慢慢来。
