示例：我的学习笔记

这篇文章是格式展示的示例，方便你看到以后写文章时能用到哪些排版。这篇笔记记录的是搭建这个网站时学到的一点东西。

标题和列表

文章里的层级标题用 h1 到 h3，列表长这样：

  • HTML 负责内容
  • CSS 负责外观
  • GitHub Pages 负责托管

引用

纸上得来终觉浅，绝知此事要躬行。

代码块

如果以后写技术笔记，代码块长这样：

<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <title>我的博客</title>
  </head>
  <body>
    <h1>你好，世界</h1>
  </body>
</html>

强调

可以给文字加 加粗、斜体，或者 链接。

以上就是写文章时最常用的几种格式，够用啦。
