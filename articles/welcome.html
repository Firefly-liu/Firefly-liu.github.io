欢迎来到我的博客

大家好，欢迎来到我的博客。

想了很久要不要建一个自己的网站，最后决定不再犹豫了。原因很简单：我想在这个属于自己的角落里，记录一些日常，留下一些想法。

这里可能会写这些东西：

  • 生活中的小事情和碎碎念
  • 学习过程中遇到的问题和笔记
  • 喜欢的东西，比如音乐、游戏、动漫
  • 偶尔的一些思考和总结

这个网站是用最朴素的 HTML 和 CSS 写成的，托管在 GitHub Pages 上，不需要租服务器，也不用花钱。

以后会慢慢更新，希望这里能成为我在互联网上的一个小家。

谢谢你的到来，愿我们在文字里相遇。
