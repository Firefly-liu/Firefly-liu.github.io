项目做了什么

这是一辆基于 ROS1 的四轮机器人小车。整体任务可以拆成四件事：听懂指令 → 知道自己在哪、要去哪 → 看清环境里的东西 → 把结果播报出来。

语音交互

离线命令词负责唤醒与关键词识别，后期改为在线语音识别；语音播报走离线 TTS 与音频播放两条路。

ROS Topic 离线命令词 TTS

导航与建图

gmapping / hector 建图，多导航点巡线，局部规划器从 dwa 换到 teb，并用 rosbridge 打通跨设备遥控。

gmapping teb TF rosbridge

视觉检测

自建数据集训练 YOLOv8，导出 onnx 后转成 rknn，在 RK3588 的 NPU 上做多线程推理。

YOLOv8 ONNX RKNN

文字识别

RapidOCR 做板面文字识别，检测 + 识别两阶段流水线从 CPU 搬到 NPU，帧率提升 20 倍以上。

RapidOCR PP-OCRv4 多线程

备赛时间线

阶段一

环境搭建

系统选择、ROS 安装、Gazebo 仿真调试。这一段（前届记录）翻车最多，重装过系统、烧录过 TF 卡。

阶段二

语音与导航

打通语音唤醒与播报（前届），单点导航 → 多点导航，调通建图与坐标变换。

阶段三

视觉与模型部署

从 YOLOv5 换到 YOLOv8，自建数据集训练（前届），跑通 pt → onnx → rknn 全链路并部署上车。

阶段四

系统整合与比赛

用 sh 脚本和 launch 文件串联各子系统，处理资源冲突，最后把 OCR 搬上 NPU 完成收尾。
