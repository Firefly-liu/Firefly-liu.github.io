关于我

一个还在读书的工科生，喜欢折腾系统和机器人。

在学校电子协会带学弟，写 ROS，焊板子，顺便教一群人怎么点亮第一颗 LED。

这个站上大部分东西都跟那台机器人小车有关——装系统、跑视觉、把模型塞进 NPU。剩下的是些没地方放的碎碎念。

网站是手写的 HTML 和 CSS，挂在 GitHub Pages 上。没有后台、没有服务器，改一个字就得重新推一次。我喜欢这样。
