关于我

你好呀，我是 firefly_liu，这个博客的主人。

这个网站是我用纯 HTML 和 CSS 亲手搭起来的静态博客，免费托管在 GitHub Pages 上，没有服务器，也没有后台。

这里的绝大部分内容围绕一台机器人小车：从装系统、跑 ROS，到训练视觉模型、把它部署到板子的 NPU 上。我是个记性不太好的人，所以习惯把踩过的坑一条条写下来——既方便自己回看，也希望下一个接手的人能少走点弯路。

这个站点怎么搭的

  • 纯手写 HTML + CSS，没有框架、没有构建步骤；
  • 文章就是 articles/ 下的静态页面，改完上传就能更新；
  • 背景图从 images/desktop/ 和 images/mobile/ 里随机取，按屏幕宽度自动切换；
  • 萤火虫、星空、流星、点击爆光这些特效都在 js/effects.js 里，删掉那行 script 就能全部关掉。
